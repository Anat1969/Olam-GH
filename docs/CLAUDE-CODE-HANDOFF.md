# פרומפט פתיחה ל-Claude Code

העתיקי את כל הבלוק הבא לתוך Claude Code, בתיקייה של הריפו `olam-gh`:

```
קרא את CLAUDE.md, SPEC.md ו-README.md בשורש הריפו.
קרא את ההנחיות הכלליות ב-https://github.com/Anat1969/Claude-GH (CLAUDE.md וסקילים anat-app-builder ו-anat-design-language). הן גוברות על כל כלל אחר.

משימה: שלב 0 ושלב 1 מתוך SPEC.md.

1. לאמת את רשומות הפיילוט ב-data/ מול המקורות. לכל רשומה שאומתה: verified=true ו-accessedAt. לכל רשומה שלא אומתה: להשאיר false ולרשום בסיכום למה.
2. לאשר את ה-DNA בטיוטה ב-CLAUDE.md ולהציג לענת לאישור לפני שמשתמשים בו בעיצוב.
3. לבנות MVP: Vite + React + TypeScript, ציר זמן D3 לתחום אחד (שכל / פיזיקה), כרטיס דמות, מחליק זמן. עברית RTL, כפתורים מרובעים, ללא אייקונים בממשק, סרגל עליון עם שם האפליקציה וכפתור `<ai-menu>` יחיד.
4. Playwright: בדיקות מול vite preview, צילומי מסך ב-1280 וב-390.
5. לפני מיזוג: לוודא שהבדיקות ירוקות. מיזוג ל-main, ומיד פריסה ל-Vercel.
6. לרשום את האפליקציה ב-aoa_apps עם כתובת GitHub וכתובת Vercel.
7. לדווח לענת בפורמט: מה אני הולך לעשות (בפתיחה), מה עשיתי, מה למדתי, מה אני ממליץ, וכתובת סופית בשורה אחת.

אל תעצור לשאלות שאפשר להכריע. כל החלטה קטנה נרשמת כהנחה בסיכום.
```

## מתי לעבור
אחרי שהמסמכים נכנסו למאגר ונדחפו ל-main, עוברים ל-Claude Code. השיחה הזו מתאימה לאפיון ולתוכן. הבנייה והבדיקות יתבצעו שם.
